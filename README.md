# Analytical Psychology Code

Open computational scaffolding for the Analytical Psychology knowledge series.

This repository supports article-level examples for analytical psychology, Jungian psychology, depth psychology, complexes, dreams, symbolic process, archetypes, persona, shadow, individuation, active imagination, trauma, clinical process, alchemy, religion, post-Jungian developments, cultural critique, and epistemology.

The examples are synthetic and educational. They are designed to support transparent modeling, qualitative coding, symbolic-process simulation, reproducible notebooks, and article-linked computational demonstrations. They are not clinical, diagnostic, therapeutic, or automated dream-interpretation tools.

## Structure

Each article folder contains:

- `python/`
- `r/`
- `julia/`
- `cpp/`
- `fortran/`
- `c/`
- `rust/`
- `go/`
- `sql/`
- `notebooks/`
- `docs/`
- `data/raw/`
- `data/processed/`
- `outputs/`
