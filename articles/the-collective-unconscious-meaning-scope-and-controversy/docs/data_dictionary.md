# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real therapy records, clinical material, private dreams, sacred texts, living traditions, religious communities, cultural-memory archives, or empirical findings.

## `symbolic_corpora.csv`

| Field | Description |
|---|---|
| `doc_id` | Synthetic document identifier |
| `source_type` | Synthetic source category such as dream, myth, religious, literary, or cultural memory |
| `culture_group` | Synthetic context label |
| `text` | Synthetic short narrative used for motif analysis |

## `motif_dictionary.csv`

| Field | Description |
|---|---|
| `motif` | Symbolic motif term |
| `cluster` | Broad interpretive cluster |
| `description` | Possible symbolic range for the motif |
| `interpretive_caution` | Guardrail against fixed, inflated, extractive, or culturally flattening interpretation |

## Responsible-use note

These variables are conceptual demonstrations. They are not validated psychological, clinical, theological, anthropological, diagnostic, dream-interpretive, cultural-memory, or assessment measures.
