# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological, clinical, theological, anthropological, diagnostic, predictive, cultural-memory, or dream-interpretive measures and should not be interpreted as measurements of real people or real traditions.

## Modeling logic

The article’s core claim is that the collective unconscious is a contested hypothesis about recurrent structuring tendencies in symbolic life.

A simplified symbolic-output model is:

```text
symbolic expression =
  personal biography
  + cultural context
  + latent structural pattern
  + historical transmission
  + genre convention
  + error
```

A simplified recurrence-strength model is:

```text
recurrence strength =
  cluster stability
  + weighted co-occurrence strength
  + cross-context recurrence
  - alternative-explanation strength
```

A simplified responsible-interpretation model is:

```text
interpretive confidence =
  recurrence evidence
  + contextual fit
  + affective salience
  + symbolic function
  - transmission explanation
  - genre explanation
  - cultural flattening risk
  - interpretive inflation risk
```

## Interpretive safeguards

- Co-occurrence is not proof of the collective unconscious.
- Recurrence is not proof of universal sameness.
- Similar motifs may perform different symbolic functions in different traditions.
- Dreams require personal association and clinical context.
- Religious symbols should not be reduced to psychology alone.
- Cultural-memory imagery may be historical and political, not only archetypal.
- Comparative analysis should not extract symbols from living traditions.
- Archetypal language should not romanticize suffering, trauma, domination, or harm.
- Strong imagery does not automatically justify collective-unconscious interpretation.
