# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real patients, therapists, treatment outcomes, clinical notes, supervision records, or empirical findings.

## `synthetic_relational_jungian_therapy.csv`

| Field | Description |
|---|---|
| `case_id` | Synthetic row identifier |
| `clinical_presentation` | Illustrative clinical presentation category |
| `session` | Synthetic session marker |
| `relational_safety` | Stylized therapeutic field safety |
| `attachment_security` | Stylized attachment security in the treatment field |
| `affect_regulation` | Stylized capacity to feel and regulate affect |
| `rupture_intensity` | Stylized intensity of rupture, misattunement, or field conflict |
| `repair_capacity` | Stylized capacity to work through rupture and restore relational trust |
| `shame_load` | Stylized developmental shame pressure |
| `fragmentation` | Stylized dissociation, fragmentation, or self-state discontinuity |
| `embodied_safety` | Stylized bodily sense of enough safety to remain present |
| `symbolic_capacity` | Stylized capacity to dream, imagine, symbolize, and reflect |
| `dream_richness` | Stylized richness of dream and image life |
| `reflective_self` | Stylized self-reflective and mentalizing capacity |
