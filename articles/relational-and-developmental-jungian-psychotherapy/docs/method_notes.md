# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological, clinical, therapeutic, or outcome measures and should not be interpreted as measurements of real patients, therapists, sessions, or treatment effects.

## Modeling logic

The article’s core claim is that relational and developmental Jungian psychotherapy supports integration by strengthening relational safety, affect regulation, repair capacity, symbolic capacity, embodied safety, and reflective selfhood while reducing fragmentation and developmental shame.

A simplified developmental-integration model is:

```text
developmental integration =
  relational safety
  + attachment security
  + affect regulation
  + repair capacity
  + embodied safety
  + symbolic capacity
  + reflective self
  - fragmentation
  - shame load
  - rupture intensity
```

A simplified symbolic-capacity model is:

```text
symbolic capacity =
  relational safety
  + affect regulation
  + repair capacity
  + embodied safety
  - shame load
  - fragmentation
```

A simplified rupture-risk model is:

```text
rupture risk =
  rupture intensity
  + shame load
  + fragmentation
  - repair capacity
  - relational safety
  - reflective self
```

## Limits

These examples are conceptual demonstrations. They should not be used for:

- diagnosis;
- therapy;
- psychological assessment;
- treatment recommendation;
- therapist evaluation;
- clinical decision-making;
- employee screening;
- workplace surveillance;
- individual scoring;
- clinical triage;
- claims about empirical effectiveness;
- proof or disproof of Jungian psychotherapy.

## Recommended use

Use these files to demonstrate reproducible research structure, transparent assumptions, synthetic simulation, dynamic field-network modeling, and conceptual-method documentation in scholarly writing.
