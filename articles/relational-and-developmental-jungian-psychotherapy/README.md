# Relational and Developmental Jungian Psychotherapy

This companion scaffold supports the article **“Relational and Developmental Jungian Psychotherapy”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s argument into reproducible, synthetic-data workflows. The goal is not to diagnose people, evaluate therapists, predict clinical outcomes, recommend treatment, or reduce psychotherapy to a formula. The goal is to demonstrate how relational safety, attachment security, affect regulation, rupture intensity, repair capacity, shame load, fragmentation, embodied safety, symbolic capacity, dream richness, reflective selfhood, and developmental integration can be represented transparently in conceptual modeling.

## Repository purpose

This article argues that relational and developmental Jungian psychotherapy expands classical analytical psychology by placing therapeutic relationship, early development, attachment, affect regulation, rupture-and-repair, embodied memory, symbolic capacity, and co-created experience at the center of clinical work.

The code examples extend that argument through:

- synthetic relational-therapy session data;
- developmental-integration simulation;
- symbolic-capacity and dream-richness modeling;
- rupture-and-repair scenario modeling;
- dynamic relational-field network workflows;
- reproducible tables and figures;
- multi-language computational scaffolding;
- documented responsible-use limits.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, symbolic-process analysis, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, therapist evaluation, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Inspect the synthetic data in `data/raw/synthetic_relational_jungian_therapy.csv`.
3. Run the R workflow in `r/simulate_relational_jungian_therapy.R`.
4. Run the Python workflow in `python/relational_jungian_field_network.py`.
5. Use `sql/schema.sql` to inspect the relational-therapy schema.
6. Treat all outputs as illustrative and synthetic, not empirical findings or clinical claims.
