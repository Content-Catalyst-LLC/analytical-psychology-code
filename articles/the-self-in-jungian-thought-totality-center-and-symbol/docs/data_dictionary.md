# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real patients, therapy records, clinical material, spiritual assessments, dream records, mental-health assessments, employment records, or empirical findings.

## `synthetic_self_integration_panel.csv`

| Field | Description |
|---|---|
| `case_id` | Synthetic case-period identifier |
| `person_id` | Synthetic person identifier |
| `time` | Ordered synthetic developmental time step |
| `individuation_pattern` | Synthetic pattern such as stable ego development, persona crack, shadow integration, center-symbol emergence, inflation risk, or fragmentation repair |
| `ego_coherence` | Stylized ego organization and continuity |
| `unconscious_activation` | Stylized activation of unconscious contents |
| `symbolic_center_strength` | Stylized strength of center-symbol imagery or symbolic orientation |
| `shadow_pressure` | Stylized activation of disowned material |
| `relational_coordination` | Stylized relation among psychic domains and relational life |
| `disjunction` | Stylized fragmentation or unresolved contradiction |
| `inflation_risk` | Stylized risk of ego identification with symbolic authority |
| `totality_score` | Synthetic symbolic totality score |
| `differentiation_score` | Synthetic differentiation-with-relation score |
| `self_relation_index` | Synthetic ego-Self relation indicator |

## `psychic_network_nodes.csv`

| Field | Description |

| `cluster` | Broad cluster such as conscious center, adaptation, unconscious, symbolic, embodied, function, or Self-symbol |

## Responsible-use note

These variables are conceptual demonstrations. They are not validated psychological, clinical, therapeutic, diagnostic, predictive, spiritual, dream-interpretive, or assessment measures.
