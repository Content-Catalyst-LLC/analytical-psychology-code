# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological, clinical, therapeutic, diagnostic, moral-ranking, predictive, or mental-health measures and should not be interpreted as measurements of real people.

## Modeling logic

The article’s core claim is that the shadow forms where conscious identity excludes traits, affects, motives, or capacities that remain active in the psyche.

A simplified shadow-activation model is:

```text
shadow activation =
  latent disowned material * cue intensity
  + shadow discrepancy
  + affective charge
  - reflective capacity
```

A simplified projection model is:

```text
projection intensity =
  shadow activation
  + affective charge
  + persona rigidity
  - reflective capacity
```

A simplified integration model is:

```text
integration capacity =
  reflective capacity
  - projection intensity
  - shame response
  + developmental time
```

A simplified network model is:

```text
Shadow pressure increases when shadow nodes remain weakly connected to
conscious identity but strongly connected to projection, shame, defensiveness,
or withdrawal responses. Reflection and integration create alternative paths
toward responsibility and repair.
```

## Interpretive safeguards

- The shadow is not simply evil.
- Recognition is not permission.
- Projection is not the same as moral criticism.
- Real harm should not be reduced to psychology.
- A critic may be right.
- Shame collapse is not the same as responsibility.
- Shadow work should not be used for diagnosis, moral ranking, workplace evaluation, or authority protection.
- Crisis, trauma, suicidality, psychosis, mania, severe dissociation, or unstable reality testing require appropriate professional care, not symbolic speculation.
