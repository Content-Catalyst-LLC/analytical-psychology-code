# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real people, therapy records, dream journals, clinical material, mental-health assessments, symbolic interpretations, or empirical findings.

## `synthetic_active_imagination_dialogue.csv`

| Field | Description |
|---|---|
| `case_id` | Synthetic row identifier |
| `dialogue_mode` | Illustrative active-imagination mode |
| `time` | Synthetic developmental time marker |
| `ego_mediation` | Stylized ego presence, memory, discrimination, and containment |
| `imaginal_activation` | Stylized intensity of imaginal material |
| `reflective_response` | Stylized conscious response and interpretive participation |
| `symbolic_relation` | Stylized ability to relate to symbolic material without literalism or dismissal |
| `ethical_containment` | Stylized ability to test symbolic material against life and responsibility |
| `destabilization_risk` | Stylized risk under high imaginal pressure and weak mediation |
| `inflation_risk` | Stylized risk of overidentifying with symbolic authority |
| `dialogue_quality` | Stylized quality of sustained symbolic dialogue |
| `integration_score` | Synthetic conceptual integration index, not a clinical or therapeutic measure |

## `symbolic_dialogue_construct_dictionary.csv`

| Field | Description |

| `construct` | Variable or conceptual construct |
| `cluster` | Broad interpretive cluster |
| `notes` | Interpretive note and caution |
