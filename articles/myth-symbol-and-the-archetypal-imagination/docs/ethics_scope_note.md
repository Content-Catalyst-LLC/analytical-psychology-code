# Ethics and Scope Note

The materials in this folder are designed for scholarly demonstration and reproducible conceptual modeling.

They should not be used to:

- prove archetypes;
- appropriate sacred traditions;
- interpret private dreams;
- classify religions;
- rank cultures;
- evaluate communities;
- automate myth interpretation;
- extract symbols from marginalized communities without context or permission;
- flatten religious traditions into psychological abstractions;
- replace historical, anthropological, theological, literary, political, or clinical expertise;
- justify political myth, nationalist myth, exclusion, domination, or violence.

Symbolic analysis is strongest when it supports humility, context, historical depth, ethical care, and attention to power. Recurrence should be studied with caution; difference should not be erased.
