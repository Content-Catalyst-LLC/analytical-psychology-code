# Data Dictionary

The files in `data/raw/` are synthetic or placeholder demonstration data. They do not represent private dreams, sacred community-held materials, restricted ritual texts, confidential interviews, psychological records, or empirical proof of archetypes.

## `myth_symbol_corpus.csv`

| Field | Description |
|---|---|
| `doc_id` | Synthetic or placeholder document identifier |
| `source_type` | Source category, such as synthetic myth, synthetic dream report, placeholder ritual text, literary text, or political speech |
| `culture_group` | Broad placeholder context label; not a real cultural classification |
| `time_period` | Broad placeholder period label |
| `title` | Synthetic or placeholder title |
| `text` | Synthetic demonstration text containing motif terms |

## `motif_dictionary.csv`

| Field | Description |
|---|---|
| `motif` | Curated symbolic motif category |
| `term` | Search term associated with the motif |
| `cluster` | Interpretive cluster, such as renewal, transformation, threshold, shadow, orientation, persona, or political myth |
| `notes` | Interpretive note and caution |

## Responsible-use note

The corpus is designed for method demonstration. Do not treat outputs as evidence that motifs have identical meanings across traditions. Motif recurrence requires close reading, historical context, linguistic knowledge, theological care, political analysis, and ethical interpretation.
