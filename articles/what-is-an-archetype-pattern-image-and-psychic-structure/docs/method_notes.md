# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological, clinical, theological, anthropological, diagnostic, predictive, or dream-interpretive measures.

## Modeling logic

A simplified latent-pattern model:

```text
symbolic output =
  latent archetypal factors
  + cultural context
  + personal context
  + textual or ritual context
  + error
```

A simplified recurrence-strength model:

```text
recurrence strength =
  cluster stability
  + weighted co-occurrence strength
  + cross-context recurrence
  - cultural flattening risk
```

## Interpretive safeguards

- Archetypes are not fixed images.
- Recurrence is not proof of universal sameness.
- Similar motifs may perform different symbolic functions in different traditions.
- Dreams require personal association and clinical context.
- Religious symbols should not be reduced to psychology alone.
- Comparative analysis should not extract symbols from living traditions.
- Archetypal language should not romanticize suffering, trauma, domination, or harm.
