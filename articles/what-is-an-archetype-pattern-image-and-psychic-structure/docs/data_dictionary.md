# Data Dictionary

The raw data are synthetic and illustrative. They do not represent therapy records, clinical material, private dreams, sacred texts, living traditions, religious communities, or empirical findings.

## `archetypal_corpus.csv`

| Field | Description |
|---|---|
| `doc_id` | Synthetic document identifier |
| `source_type` | Synthetic source category such as dream, myth, literary, or ritual |
| `culture_group` | Synthetic context label |
| `text` | Synthetic short narrative used for motif analysis |

## `motif_dictionary.csv`

| Field | Description |
|---|---|
| `motif` | Symbolic motif term |
| `cluster` | Broad interpretive cluster |
| `description` | Possible symbolic range |
| `interpretive_caution` | Guardrail against fixed, inflated, extractive, or culturally flattening interpretation |
