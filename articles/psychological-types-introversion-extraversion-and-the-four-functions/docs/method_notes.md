# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological, clinical, therapeutic, diagnostic, psychometric, personality-assessment, employment, or life-outcome measures and should not be interpreted as measurements of real people or real types.

## Modeling logic

The article’s core claim is that Jungian typology is a theory of conscious orientation, function differentiation, one-sidedness, unconscious compensation, and developmental integration.

A simplified conscious-coherence model is:

```text
conscious coherence =
  dominant function strength
  + attitude organization
  - function variance
  + reflective capacity
```

A simplified compensation-strain model is:

```text
compensation strain =
  dominant-inferior function gap
  + function variance
  + unconscious pressure
  - reflective capacity
```

A simplified developmental-integration model is:

```text
developmental integration =
  inferior function access
  + symbolic relation
  + reflective capacity
  - function variance
  - compensation strain
```

## Limits

These examples are conceptual demonstrations. They should not be used for:

- diagnosis;
- therapy;
- psychological assessment;
- personality assessment;
- typological labeling;
- psychometric classification;
- treatment recommendation;
- clinical decision-making;
- hiring;
- promotion;
- compensation decisions;
- employment screening;
- workplace surveillance;
- individual scoring;
- individual evaluation;
- advice about relationships, careers, religion, or life choices;
- claims about empirical effectiveness;
- proof or disproof of Jungian typology.

## Recommended use

Use these files to demonstrate reproducible research structure, transparent assumptions, synthetic simulation, dynamic functional-network modeling, and conceptual-method documentation in scholarly writing.
