# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real people, personality-test results, therapy records, psychological assessments, employment records, hiring data, clinical outcomes, or empirical findings.

## `synthetic_psychological_types.csv`

| Field | Description |
|---|---|
| `case_id` | Synthetic row identifier |
| `dominant_function` | Illustrative dominant Jungian function |
| `inferior_function` | Illustrative inferior Jungian function |
| `dominant_attitude` | Illustrative introverted or extraverted attitude |
| `time` | Synthetic developmental time marker |
| `thinking` | Stylized thinking-function value |
| `feeling` | Stylized feeling-function value |
| `sensation` | Stylized sensation-function value |
| `intuition` | Stylized intuition-function value |
| `attitude_score` | Stylized attitude score; negative = introversion, positive = extraversion |
| `dominant_strength` | Highest value among the four functions |
| `inferior_strength` | Lowest value among the four functions |
| `function_variance` | Stylized measure of uneven function differentiation |
| `unconscious_pressure` | Stylized compensatory pressure from unconscious material |
| `compensation_strain` | Stylized strain created by dominant-inferior gap, variance, and unconscious pressure |
| `reflective_capacity` | Stylized capacity for reflective containment and symbolic interpretation |
| `symbolic_relation` | Stylized capacity to relate to symbols, dreams, and inferior-function material |
| `conscious_coherence` | Stylized coherence produced by differentiated conscious orientation |
| `developmental_integration` | Stylized integration of functions, symbolic relation, and reflection |
