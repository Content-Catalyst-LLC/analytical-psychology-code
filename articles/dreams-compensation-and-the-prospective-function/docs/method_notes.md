# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological, clinical, therapeutic, diagnostic, dream-interpretive, predictive, or mental-health measures and should not be interpreted as measurements of real people or real dreams.

## Modeling logic

The article’s core claim is that dreams may have both compensatory and prospective functions.

A simplified compensatory model is:

```text
compensatory intensity =
  unconscious pressure
  - conscious one-sidedness
  + affective intensity
  - reflective capacity
```

A simplified prospective model is:

```text
prospective intensity =
  latent growth tendency
  + symbolic literacy
  + reflective capacity
  + prior dream material
```

A simplified dream-output model is:

```text
dream output =
  compensatory intensity
  + prospective intensity
  + affective intensity
  + previous dream output
```

A simplified integration model is:

```text
integration signal =
  prospective intensity
  + reflective capacity
  + symbolic literacy
  - absolute compensatory intensity
```

## Interpretive safeguards

- Prospective dream interpretation is not prophecy.
- Motif recurrence does not prove development.
- Symbolic centrality is an interpretive clue, not clinical evidence.
- Dreams should not be interpreted apart from the dreamer’s associations, context, series, life situation, and actual capacity.
- Crisis, trauma, suicidality, psychosis, mania, severe dissociation, or unstable reality testing require appropriate professional care, not symbolic speculation.
