# Why Analytical Psychology Still Matters

This companion scaffold supports the article **“Why Analytical Psychology Still Matters”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s conceptual argument into reproducible, synthetic-data workflows. The goal is not to measure individual people, diagnose psychological conditions, or turn Jungian concepts into clinical scoring instruments. The goal is to demonstrate how symbolic depth, meaning coherence, clinical utility, cultural interpretive power, revision capacity, symbolic loss, projection intensity, existential dislocation, and doctrinal rigidity can be represented in transparent conceptual models.

## Repository purpose

This article argues that analytical psychology remains relevant because it keeps symbolic, imaginal, developmental, spiritual, cultural, and clinical dimensions of psyche in view. The code examples extend that argument through:

- synthetic data simulation;
- conceptual network modeling;
- reproducible tables and figures;
- multi-language computational scaffolding;
- documented responsible-use limits.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Run the R simulation in `r/simulate_relevance.R`.
3. Run the Python concept network in `python/concept_network.py`.
4. Use `sql/schema.sql` to inspect the conceptual data structure.
5. Treat all outputs as illustrative and synthetic, not empirical findings.
