# Validation Plan

This scaffold is conceptual and synthetic. A serious empirical extension would require careful validation before making any claims about real-world psychological phenomena.

## Possible validation steps

1. Define constructs clearly.
2. Separate symbolic interpretation from empirical hypothesis.
3. Review existing clinical and cultural research.
4. Use validated scales where appropriate.
5. Obtain ethical approval for human-subjects research.
6. Avoid individual-level scoring unless the instrument is validated for that purpose.
7. Compare model outputs against qualitative evidence, clinical literature, and historical case materials.
8. Document uncertainty and avoid overclaiming.

## Non-goals

This scaffold does not validate Jungian theory. It does not prove archetypes, measure individuation, diagnose shadow material, or assess clinical outcomes.
