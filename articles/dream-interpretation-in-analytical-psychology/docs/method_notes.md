# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological, clinical, therapeutic, diagnostic, dream-interpretive, predictive, or mental-health measures and should not be interpreted as measurements of real people or real dreams.

## Modeling logic

The article’s core claim is that dream interpretation in analytical psychology requires attention to compensation, context, symbol, structure, association, amplification, and development across a dream series.

A simplified compensatory model is:

```text
compensatory signal =
  unconscious pressure
  - conscious one-sidedness
  + affective intensity
  - reflective capacity
```

A simplified symbolic recurrence model is:

```text
symbolic recurrence =
  previous dream output
  + symbolic repertoire
  + latent development
```

A simplified dream-output model is:

```text
dream output =
  compensatory signal
  + symbolic recurrence
  + affective intensity
  + latent development
```

A simplified integration model is:

```text
integration signal =
  reflective capacity
  + latent development
  + symbolic repertoire
  - absolute compensatory signal
```

## Interpretive safeguards

- Dream motifs are not fixed codes.
- Symbolic centrality is not proof of meaning.
- Motif recurrence does not automatically prove archetypal significance.
- Dream interpretation must remain grounded in personal association, dream structure, context, life situation, and ethical caution.
- Crisis, trauma, suicidality, psychosis, mania, severe dissociation, or unstable reality testing require appropriate professional care, not symbolic speculation.
