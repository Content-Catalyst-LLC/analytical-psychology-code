# Method Notes

This scaffold uses synthetic corpus data to demonstrate symbolic motif analysis. The variables and motifs are not validated psychological scales and should not be interpreted as measurements of authors, readers, cultures, students, or literary value.

## Modeling logic

The article’s core claim is that Jungian literary interpretation is strongest when symbolic richness, archetypal recurrence, formal centrality, affective charge, and historical specificity reinforce one another without collapsing into template imposition.

A simplified interpretive-depth model is:

```text
interpretive depth =
  symbolic density
  + archetypal clustering
  + formal centrality
  + affective charge
  + historical specificity
  - reductive overgeneralization
```

A simplified reductive-risk model is:

```text
reductive risk =
  universalizing pressure
  + template imposition
  - cultural specificity
  - close-reading quality
```

## Limits

These examples are conceptual demonstrations. They should not be used for:

- author diagnosis;
- psychological assessment;
- automated interpretation;
- grading students;
- ranking cultures;
- ranking literary canons;
- replacing close reading;
- proving archetypes;
- reducing historical violence to psychology.

## Recommended use

Use these files to demonstrate reproducible research structure, transparent assumptions, synthetic corpus analysis, motif-network modeling, and literary-method documentation in scholarly writing.
