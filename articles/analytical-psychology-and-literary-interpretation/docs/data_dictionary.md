# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent a real literary corpus, author psychology, reader psychology, student performance, canon ranking, or empirical proof of archetypes.

## `literary_symbol_corpus.csv`

| Field | Description |
|---|---|
| `doc_id` | Synthetic document identifier |
| `genre` | Illustrative literary genre |
| `period` | Synthetic historical-period label |
| `author` | Synthetic author label |
| `title` | Synthetic text title |
| `text` | Short synthetic text excerpt containing motif terms |

## `motif_dictionary.csv`

| Field | Description |
|---|---|
| `motif` | Curated motif term used for symbolic analysis |
| `cluster` | Broad interpretive cluster for the motif |
| `notes` | Cautionary notes about possible meanings and contextual variation |
