# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real people, therapy records, psychological assessments, personality-test results, hiring data, employment records, or empirical findings.

## `synthetic_jungian_personality.csv`

| Field | Description |
|---|---|
| `case_id` | Synthetic row identifier |
| `dominant_function` | Illustrative dominant Jungian function |
| `dominant_attitude` | Illustrative introverted or extraverted attitude |
| `time` | Synthetic developmental time marker |
| `conscious_orientation` | Stylized conscious style and ego-organized orientation |
| `persona_identification` | Stylized identification with social role, public image, or adaptive mask |
| `shadow_acknowledgment` | Stylized capacity to recognize disowned psychic material |
| `symbolic_relation` | Stylized capacity to relate to dreams, images, myth, and symbolic life |
| `typological_flexibility` | Stylized capacity to move beyond rigid dominant-function one-sidedness |
| `complex_activation` | Stylized activation of affectively charged complexes |
| `unconscious_compensation` | Stylized compensatory pressure from unconscious material |
| `reflective_capacity` | Stylized capacity to hold ambiguity, projection, and psychic tension |
| `developmental_integration` | Stylized integration of personality domains over time |
| `onesidedness` | Stylized discrepancy among developed and neglected psychic domains |
| `personality_state` | Synthetic conceptual index of personality organization, not an assessment score |
