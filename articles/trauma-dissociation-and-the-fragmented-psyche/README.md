# Trauma, Dissociation, and the Fragmented Psyche

This companion scaffold supports the article **“Trauma, Dissociation, and the Fragmented Psyche”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s argument into reproducible, synthetic-data workflows. The goal is not to diagnose people, predict crisis risk, evaluate treatment, recommend therapy, or reduce trauma to a formula. The goal is to demonstrate how affect intensity, ego integration, symbolic capacity, relational safety, bodily regulation, dissociation, nightmare intrusion, memory continuity, symbolic recovery, and integration potential can be represented transparently in conceptual modeling.

## Repository purpose

This article argues that trauma is not merely a painful event remembered afterward, but an overwhelming experience that may disrupt the organization of psyche: separating affect from memory, body from meaning, and self-state from self-state. Dissociation is treated as both protection and division, while healing is modeled as gradual reconnection among body, affect, memory, symbol, relationship, and self-representation.

The code examples extend that argument through:

- synthetic trauma-and-dissociation data;
- traumatic-overwhelm and dissociation simulation;
- symbolic-recovery and memory-continuity modeling;
- fragmented-psyche dynamic network workflows;
- reproducible tables and figures;
- multi-language computational scaffolding;
- documented responsible-use limits.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, symbolic-process analysis, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, crisis assessment, risk prediction, clinical decision-making, treatment recommendation, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Inspect the synthetic data in `data/raw/synthetic_trauma_dissociation.csv`.
3. Run the R workflow in `r/simulate_trauma_dissociation.R`.
4. Run the Python workflow in `python/fragmented_psyche_network.py`.
5. Use `sql/schema.sql` to inspect the trauma-and-dissociation schema.
6. Treat all outputs as illustrative and synthetic, not empirical findings or clinical claims.
