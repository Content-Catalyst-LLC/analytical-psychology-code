# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological, clinical, therapeutic, diagnostic, or risk measures and should not be interpreted as measurements of real patients, trauma histories, crises, treatment effects, or clinical outcomes.

## Modeling logic

The article’s core claim is that trauma and dissociation can be understood as a breakdown in psychic connectivity under overwhelming affect load. Dissociation protects by separating affect, memory, body, and self-state, but later constrains integration. Healing involves gradual rebuilding of relation among body, affect, memory, symbol, and self-representation.

A simplified dissociation model is:

```text
dissociation =
  affect intensity
  + developmental trauma load
  + nightmare intrusion
  - ego integration
  - symbolic capacity
  - relational safety
  - bodily regulation
```

A simplified symbolic recovery model is:

```text
symbolic recovery =
  symbolic capacity
  + memory continuity
  + relational safety
  + bodily regulation
  + witnessing capacity
  - nightmare intrusion
  - dissociation
```

A simplified integration model is:

```text
integration potential =
  ego integration
  + symbolic capacity
  + relational safety
  + bodily regulation
  + memory continuity
  + symbolic recovery
  + witnessing capacity
  - dissociation
  - nightmare intrusion
```

## Limits

These examples are conceptual demonstrations. They should not be used for:

- diagnosis;
- therapy;
- crisis assessment;
- suicide or self-harm risk prediction;
- psychological assessment;
- treatment recommendation;
- clinical decision-making;
- employee screening;
- workplace surveillance;
- individual scoring;
- clinical triage;
- claims about empirical effectiveness;
- proof or disproof of Jungian trauma theory.

## Recommended use

Use these files to demonstrate reproducible research structure, transparent assumptions, synthetic simulation, dynamic trauma-network modeling, and conceptual-method documentation in scholarly writing.
