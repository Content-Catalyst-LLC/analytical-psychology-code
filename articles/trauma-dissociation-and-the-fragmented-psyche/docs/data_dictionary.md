# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real patients, clinical records, traumatic events, treatment outcomes, risk status, or empirical findings.

## `synthetic_trauma_dissociation.csv`

| Field | Description |
|---|---|
| `case_id` | Synthetic row identifier |
| `trauma_pattern` | Illustrative trauma-pattern category |
| `time` | Synthetic time marker |
| `affect_intensity` | Stylized intensity of overwhelming affect |
| `ego_integration` | Stylized reflective continuity and ego capacity |
| `symbolic_capacity` | Stylized capacity to dream, imagine, symbolize, and reflect |
| `relational_safety` | Stylized sufficiently reliable relational containment |
| `bodily_regulation` | Stylized capacity for embodied regulation |
| `dissociation` | Stylized division of affect, memory, body, and self-state |
| `nightmare_intrusion` | Stylized nightmare or intrusive-image pressure |
| `memory_continuity` | Stylized continuity of memory and temporal selfhood |
| `symbolic_recovery` | Stylized return of dream, metaphor, image, and meaning-making capacity |
| `developmental_trauma_load` | Stylized burden of chronic early misattunement or developmental trauma |
| `witnessing_capacity` | Stylized capacity of relational field to witness without intrusion or abandonment |
