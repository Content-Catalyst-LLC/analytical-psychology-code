# Numinous Experience, Spiritual Emergency, and Symbolic Crisis

This companion scaffold supports the article **“Numinous Experience, Spiritual Emergency, and Symbolic Crisis”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s argument into reproducible, synthetic-data workflows. The goal is not to diagnose people, recommend treatment, provide spiritual direction, evaluate mystical experiences, rank religious traditions, predict crisis, or reduce spiritual life to a formula. The goal is to demonstrate how numinous intensity, symbolic containment, ego stability, trauma vulnerability, shadow awareness, relational support, sleep disruption, perceived mission, inflation risk, crisis risk, and integration potential can be represented transparently in conceptual modeling.

## Repository purpose

This article argues that numinous experience can enlarge psychic life while also destabilizing it when sacred or archetypal intensity exceeds containment. Analytical psychology is useful because it can take sacred intensity seriously without collapsing it into either pathology alone or revelation alone.

The code examples extend that argument through:

- synthetic numinous-crisis data;
- spiritual-emergency risk simulation;
- inflation-risk modeling;
- integration-potential modeling;
- ritual, relational, and symbolic containment variables;
- dynamic numinous-crisis network modeling;
- reproducible tables and figures;
- multi-language computational scaffolding;
- documented responsible-use limits.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, symbolic-process analysis, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, spiritual direction, crisis intervention, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Inspect the synthetic data in `data/raw/synthetic_numinous_crisis.csv`.
3. Run the R workflow in `r/simulate_numinous_crisis.R`.
4. Run the Python workflow in `python/numinous_crisis_network.py`.
5. Use `sql/schema.sql` to inspect the numinous-crisis schema.
6. Treat all outputs as illustrative and synthetic, not empirical findings.
