# Complexes, Affect, and Repetition in Analytical Psychology

This companion scaffold supports the article **“Complexes, Affect, and Repetition in Analytical Psychology”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s argument into reproducible, synthetic-data workflows. The goal is not to diagnose people, assess personality, interpret private clinical material, predict treatment outcomes, evaluate employees, or automate psychological judgment. The goal is to demonstrate how complex activation, affective charge, triggers, regulation, relational buffering, recurrence, projection, transference, symbolic repetition, and network dynamics can be represented transparently in conceptual modeling.

## Repository purpose

This article argues that complexes are not inert psychic contents. They are affectively charged organizations that recur, intrude, distort, and repeat. Affect gives complexes force. Repetition reveals their structure. Relational drama, projection, transference, traumatic memory, and symbolic recurrence make complexes visible as living patterns rather than static contents.

The code examples extend that argument through:

- synthetic complex-activation panel data;
- trigger, affect, regulation, and buffering variables;
- recurrence-probability modeling;
- affect-weighted network simulations;
- symbolic repetition examples;
- SQL schemas for structured recurrence analysis;
- multi-language computational scaffolding;
- responsible-use documentation.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, symbolic-process analysis, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, treatment recommendation, mental-health evaluation, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Inspect `data/raw/synthetic_complex_activation_panel.csv`.
3. Inspect `data/raw/complex_network_nodes.csv` and `data/raw/complex_network_edges.csv`.
4. Run the R workflow in `r/simulate_repeated_complex_activation.R`.
5. Run the Python workflow in `python/model_affective_complex_network.py`.
6. Use `sql/schema.sql` to inspect the recurrence-analysis schema.
7. Treat all outputs as illustrative and synthetic, not clinical or psychological findings.
