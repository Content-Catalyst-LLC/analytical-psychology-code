# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological, clinical, therapeutic, diagnostic, employment, predictive, or mental-health measures.

## Modeling logic

The article’s core claim is that complexes are affectively charged organizations that recur.

A simplified recursive model is:

```text
complex activation at time t =
  trigger intensity
  + previous affect
  + previous complex activation
  - regulation capacity
  - relational buffering
  + error
```

A simplified recurrence model is:

```text
repetition probability =
  current complex activation
  + previous complex activation
  + affect intensity
  + projection pressure
  + transference pressure
  - regulation capacity
  - relational buffering
```

A network model is:

```text
Present cues activate affect nodes.
Affect nodes activate memory, cognition, expectation, and response nodes.
Dense affect-weighted loops make the system more likely to return to familiar states.
Regulatory and relational-buffer nodes inhibit activation and create alternative pathways.
```

## Interpretive safeguards

- Complex activation is not diagnosis.
- Repetition is not always intrapsychic.
- Strong affect may be an appropriate response to real harm.
- Trauma-linked repetition requires stabilization, safety, and care before interpretation.
- Complex theory should not erase material, social, institutional, or historical conditions.
- Symbolic meaning should not romanticize suffering.
- Projection analysis should not deny that others may actually behave harmfully.
- Model outputs should never be used for employment screening, clinical decisions, surveillance, or individual evaluation.

## Recommended use

Use these files to demonstrate reproducible research structure, transparent assumptions, synthetic simulation, recurrence analysis, affective network modeling, symbolic-process research, and responsible documentation.
