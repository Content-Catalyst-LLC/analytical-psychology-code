# Method Notes

This scaffold treats anima/animus-style dynamics as symbolic otherness and relational projection without treating masculinity or femininity as fixed essence.

## Simplified models

```text
projection intensity =
  unrealized capacity
  + affective charge
  + relational trigger
  + symbolic discrepancy
  + gender-code rigidity
  - reflective mediation
```

```text
projection rigidity =
  projection intensity
  + gender-code rigidity
  - symbolic flexibility
  - reflective mediation
```

```text
symbolic integration =
  reflective mediation
  + symbolic flexibility
  - projection rigidity
  - absolute projection intensity
```

## Interpretive safeguards

- Anima and animus are not literal gender essences.
- Gendered imagery should be interpreted contextually, historically, and culturally.
- Projection is not destiny.
- The actual person should not be reduced to a symbolic figure.
- Queer, trans, and nonbinary experience should not be forced into binary categories.
- Symbolic interpretation is not gender assessment, sexuality assessment, therapy, or diagnosis.
