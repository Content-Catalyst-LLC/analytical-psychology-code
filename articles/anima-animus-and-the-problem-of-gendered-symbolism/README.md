# Anima, Animus, and the Problem of Gendered Symbolism

This companion scaffold supports the article **“Anima, Animus, and the Problem of Gendered Symbolism”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The materials translate the article’s argument into reproducible, synthetic-data workflows. They demonstrate how unrealized capacities, affective charge, relational triggers, cultural gender scripts, reflective mediation, symbolic flexibility, projection intensity, projection rigidity, and symbolic integration can be represented transparently without treating masculinity or femininity as fixed psychological essences.

## Repository purpose

This article argues that anima and animus remain psychologically important because they name the psyche’s encounter with inner otherness, projection, desire, symbolic personification, and relational overinvestment. It also criticizes the concepts’ classical gender essentialism and binary assumptions. The companion code therefore treats anima/animus-style dynamics as symbolic otherness and projection rather than as fixed masculine/feminine essence.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, symbolic-process analysis, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, treatment recommendation, mental-health evaluation, crisis intervention, gender assessment, sexuality assessment, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml`.
2. Inspect `data/raw/synthetic_symbolic_otherness_panel.csv`.
3. Inspect `data/raw/symbolic_otherness_nodes.csv` and `data/raw/symbolic_otherness_edges.csv`.
4. Run `r/model_projection_symbolic_otherness.R`.
5. Run `python/simulate_symbolic_otherness_network.py`.
6. Inspect `sql/schema.sql` and `sql/example_queries.sql`.
7. Treat all outputs as illustrative and synthetic, not clinical findings, identity assessments, gender assessments, sexuality assessments, predictions, or proof of Jungian theory.
