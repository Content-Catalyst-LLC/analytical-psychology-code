# Data Dictionary

The dataset in `data/raw/synthetic_epistemic_warrant.csv` is synthetic and illustrative. It does not represent real people, patients, clinicians, institutions, or research participants.

| Field | Description |
|---|---|
| `claim_id` | Synthetic row identifier |
| `claim_type` | Type of Jungian or analytical-psychology knowledge claim |
| `time` | Synthetic time period |
| `empirical_support` | Stylized support from empirical research or measurable evidence |
| `hermeneutic_coherence` | Stylized interpretive coherence within symbolic, textual, or clinical material |
| `clinical_utility` | Stylized practical usefulness in therapeutic or reflective contexts |
| `phenomenological_adequacy` | Stylized descriptive fit to lived inner experience |
| `contextual_specificity` | Stylized attention to cultural, historical, linguistic, and situational context |
| `methodological_explicitness` | Stylized clarity about claim type, warrant, limits, and possible disconfirmation |
| `ambiguity_inflation` | Stylized risk that a concept expands across too many domains without clarified warrant |
| `universalizing_force` | Stylized risk that a claim overgeneralizes across cultures or cases |
| `selective_evidence` | Stylized risk that examples are selected because they fit the theory |
