# Epistemology and Evidence in Analytical Psychology

This companion scaffold supports the article **“Epistemology and Evidence in Analytical Psychology”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s epistemological argument into reproducible, synthetic-data workflows. The goal is not to validate Jungian theory, diagnose people, or create psychological scoring instruments. The goal is to demonstrate how different forms of warrant—empirical support, hermeneutic coherence, clinical utility, phenomenological adequacy, contextual specificity, and methodological explicitness—can be represented transparently when evaluating mixed psychological knowledge claims.

## Repository purpose

This article argues that analytical psychology requires a plural but disciplined epistemology. Different Jungian claims require different standards of evidence:

- therapy-outcome claims require empirical and clinical evidence;
- dream interpretations require clinical-hermeneutic warrant;
- comparative-symbolic claims require historical and cultural specificity;
- phenomenological claims require descriptive precision;
- archetypal and collective-unconscious claims require careful status clarification;
- speculative claims should be marked as speculative.

The code examples extend that argument through:

- synthetic epistemic-warrant simulation;
- concept-network modeling;
- reproducible tables and figures;
- multi-language computational scaffolding;
- documented responsible-use limits.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Run the R simulation in `r/simulate_epistemic_warrant.R`.
3. Run the Python epistemic network in `python/epistemic_network.py`.
4. Use `sql/schema.sql` to inspect the synthetic claim-and-warrant structure.
5. Treat all outputs as illustrative and synthetic, not empirical findings.
