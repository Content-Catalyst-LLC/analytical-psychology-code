# Analytical Psychology, Religion, and Spiritual Experience

This companion scaffold supports the article **“Analytical Psychology, Religion, and Spiritual Experience”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s argument into reproducible, synthetic-data workflows. The goal is not to diagnose people, recommend treatment, provide spiritual direction, evaluate religious traditions, settle theological claims, or reduce religion to a formula. The goal is to demonstrate how numinous intensity, symbolic containment, ego stability, shadow awareness, ritual support, humility, perceived mission, doctrinal rigidity, religious trauma pressure, living-symbol vitality, inflation risk, and integration potential can be represented transparently in conceptual modeling.

## Repository purpose

This article argues that analytical psychology approaches religion neither as mere illusion nor as automatic proof of metaphysical truth, but as a psychologically serious domain in which symbol, ritual, numinosity, moral conflict, suffering, hope, and meaning become concentrated.

The code examples extend that argument through:

- synthetic religion-and-spiritual-experience data;
- numinous intensity and symbolic-containment simulation;
- spiritual inflation-risk modeling;
- living-symbol vitality modeling;
- dynamic religion-and-symbolic-life network modeling;
- reproducible tables and figures;
- multi-language computational scaffolding;
- documented responsible-use limits.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, symbolic-process analysis, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, spiritual direction, religious authority, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Inspect the synthetic data in `data/raw/synthetic_religion_spiritual_experience.csv`.
3. Run the R workflow in `r/simulate_religion_spiritual_experience.R`.
4. Run the Python workflow in `python/religion_spiritual_experience_network.py`.
5. Use `sql/schema.sql` to inspect the religion-and-spiritual-experience schema.
6. Treat all outputs as illustrative and synthetic, not empirical findings or theological claims.
