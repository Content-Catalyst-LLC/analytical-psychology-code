# Data Dictionary

The dataset in `data/raw/synthetic_symbolic_comparison.csv` is synthetic and illustrative. It does not represent real people, cultures, religious systems, Indigenous communities, sacred traditions, or empirical research findings.

| Field | Description |
|---|---|
| `symbol_id` | Synthetic row identifier |
| `tradition_layer` | Broad illustrative layer used for modeling; not a real cultural classification system |
| `time` | Synthetic time period |
| `recurrence` | Stylized formal recurrence or cross-context resemblance |
| `specificity` | Stylized preservation of tradition-specific meaning, function, and context |
| `linguistic_depth` | Stylized attention to language, translation, philology, and source terms |
| `ritual_context` | Stylized attention to practice, ceremony, embodiment, and ritual use |
| `dialogical_accountability` | Stylized accountability to tradition-specific scholars, practitioners, elders, or interpretive authorities |
| `universalizing_force` | Stylized pressure to interpret symbols as universal Jungian categories |
| `abstraction_pressure` | Stylized tendency to lift symbols away from local contexts into generalized forms |
| `contextual_divergence` | Stylized difference in function, meaning, ontology, or use across traditions |
| `functional_convergence` | Stylized similarity in ritual, social, theological, or psychological function |
