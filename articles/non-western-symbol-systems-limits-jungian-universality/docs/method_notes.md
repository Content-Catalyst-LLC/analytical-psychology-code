# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s methodological argument. The variables are not validated cultural measures and should not be interpreted as measurements of traditions, religions, communities, or symbolic systems.

## Modeling logic

The article’s core claim is that comparative symbolic interpretation improves when recurrence is balanced by specificity, linguistic depth, ritual context, and dialogical accountability.

A simplified comparative-quality model is:

```text
comparative quality =
  recurrence
  + specificity
  + linguistic depth
  + ritual context
  + dialogical accountability
  - universalizing force
  - abstraction pressure
```

A simplified flattening-risk model is:

```text
flattening risk =
  universalizing force
  + abstraction pressure
  - specificity
  - dialogical accountability
  - linguistic depth
```

A simplified equivalence-claim model is:

```text
equivalence claim strength =
  recurrence
  + functional convergence
  - contextual divergence
```

## Limits

These examples are conceptual demonstrations. They should not be used for:

- ranking cultures;
- evaluating religions;
- interpreting sacred systems without context;
- validating archetypes;
- diagnosing individuals;
- psychological assessment;
- workplace screening;
- surveillance;
- individual scoring;
- claims about real traditions.

## Recommended use

Use these files to demonstrate reproducible research structure, transparent assumptions, synthetic simulation, layered-network modeling, and conceptual-method documentation in scholarly writing.
