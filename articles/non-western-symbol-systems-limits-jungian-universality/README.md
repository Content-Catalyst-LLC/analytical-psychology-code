# Non-Western Symbol Systems and the Limits of Jungian Universality

This companion scaffold supports the article **“Non-Western Symbol Systems and the Limits of Jungian Universality”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s methodological argument into reproducible, synthetic-data workflows. The goal is not to rank cultures, validate archetypes, evaluate religions, or interpret sacred systems outside their own traditions. The goal is to demonstrate how recurrence, specificity, linguistic depth, ritual context, dialogical accountability, universalizing force, abstraction pressure, contextual divergence, and flattening risk can be represented transparently in conceptual comparative models.

## Repository purpose

This article argues that cross-cultural symbolic comparison requires both courage and restraint. Jungian psychology remains valuable when it notices symbolic recurrence without reducing living traditions to universal archetypal evidence. The code examples extend that argument through:

- synthetic comparative-quality simulation;
- layered cross-cultural symbol-network modeling;
- flattening-risk demonstrations;
- reproducible tables and figures;
- multi-language computational scaffolding;
- documented responsible-use limits.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, cultural ranking, religious evaluation, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Run the R simulation in `r/simulate_symbolic_comparison.R`.
3. Run the Python layered network model in `python/layered_symbol_network.py`.
4. Use `sql/schema.sql` to inspect the synthetic comparative-symbol structure.
5. Treat all outputs as illustrative and synthetic, not empirical findings.
