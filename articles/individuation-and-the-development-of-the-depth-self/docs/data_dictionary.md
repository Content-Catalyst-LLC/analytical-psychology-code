# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real people, therapy records, psychological assessments, life outcomes, clinical outcomes, or empirical findings.

## `synthetic_individuation_depth_self.csv`

| Field | Description |
|---|---|
| `case_id` | Synthetic row identifier |
| `individuation_pathway` | Illustrative individuation-pattern category |
| `time` | Synthetic developmental time marker |
| `ego_coherence` | Stylized ego continuity, reflective identity, and reality-testing capacity |
| `persona_identification` | Stylized identification with social role, adaptive mask, approval, achievement, or image |
| `shadow_acknowledgment` | Stylized capacity to recognize disowned psychic material |
| `symbolic_relation` | Stylized capacity to relate to dreams, symbols, images, myths, and active imagination |
| `complex_activation` | Stylized intensity of affectively charged patterns and repetitive possession |
| `reflective_capacity` | Stylized capacity to hold ambiguity, tension, projection, and unconscious material |
| `body_awareness` | Stylized inclusion of bodily affect, instinct, sensation, and limitation |
| `ethical_accountability` | Stylized moral responsibility under shadow integration and self-knowledge |
| `relational_life` | Stylized capacity for projection withdrawal, love, conflict, repair, and truthful relationship |
| `dream_function` | Stylized compensatory and prospective symbolic activity |
| `onesidedness` | Stylized destructive discrepancy among psychic domains |
| `compensation_pressure` | Stylized pressure from psyche to correct one-sidedness |
| `depth_self_integration` | Stylized integration of ego, shadow, symbol, body, ethics, relationship, and Self-orientation |
| `individuation_score` | Synthetic conceptual individuation index, not a real assessment score |
