# The Personal Unconscious and the Theory of Complexes

This companion scaffold supports the article **“The Personal Unconscious and the Theory of Complexes”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s argument into reproducible, synthetic-data workflows. The goal is not to diagnose people, assess personality, interpret private clinical material, predict treatment outcomes, evaluate employees, or automate psychological judgment. The goal is to demonstrate how personal-unconscious contents, complex activation, affective charge, associative clustering, triggers, regulation, contextual support, projection, transference, symbolic repetition, and network dynamics can be represented transparently in conceptual modeling.

## Repository purpose

This article argues that the personal unconscious is the biographical field in which forgotten, repressed, neglected, unrealized, and emotionally charged material remains active beneath deliberate awareness. Within that field, complexes function as affectively charged clusters of memory, image, expectation, bodily readiness, fantasy, and meaning.

The code examples extend that argument through:

- synthetic personal-unconscious and complex-activation data;
- trigger, affect, regulation, and contextual-support variables;
- recurrence-probability modeling;
- associative complex-network simulations;
- symbolic repetition examples;
- SQL schemas for structured recurrence analysis;
- multi-language computational scaffolding;
- responsible-use documentation.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, symbolic-process analysis, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, treatment recommendation, mental-health evaluation, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Inspect `data/raw/personal_unconscious_complex_activation_panel.csv`.
3. Inspect `data/raw/associative_complex_nodes.csv` and `data/raw/associative_complex_edges.csv`.
4. Run the R workflow in `r/model_personal_unconscious_complex_activation.R`.
5. Run the Python workflow in `python/simulate_associative_complex_network.py`.
6. Use `sql/schema.sql` to inspect the recurrence-analysis schema.
7. Treat all outputs as illustrative and synthetic, not clinical or psychological findings.
