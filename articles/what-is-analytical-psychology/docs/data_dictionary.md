# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real dream records, clinical notes, therapy transcripts, religious evidence, private narratives, or empirical proof of archetypes.

## `symbolic_corpus.csv`

| Field | Description |
|---|---|
| `document_id` | Synthetic document identifier |
| `source_type` | Synthetic narrative type such as dream, myth, literary, clinical narrative, active imagination, or religious symbolism |
| `phase` | Synthetic developmental or interpretive phase |
| `text` | Synthetic symbolic text |
| `interpretive_note` | Short note about symbolic motifs |

## `symbol_dictionary.csv`

| Field | Description |
|---|---|
| `symbol` | Symbolic motif term |
| `cluster` | Broad symbolic cluster |
| `description` | General interpretive description |
| `interpretive_caution` | Guardrail against overinterpretation |

## `analytical_psychology_concepts.csv`

| Field | Description |
|---|---|
| `concept` | Analytical psychology concept |
| `domain` | Conceptual domain |
| `definition` | Brief working definition |
| `responsible_use_note` | Guardrail against misuse |

## Responsible-use note

These variables are conceptual demonstrations. They are not validated psychological, clinical, therapeutic, diagnostic, religious, cultural, predictive, employment, personality, mental-health, or assessment measures.
