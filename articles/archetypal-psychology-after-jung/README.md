# Archetypal Psychology After Jung

This companion scaffold supports the article **“Archetypal Psychology After Jung”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s argument into reproducible, synthetic-data workflows. The goal is not to diagnose people, validate archetypal psychology, score patients, or reduce imaginal life to a formula. The goal is to demonstrate how psychic plurality, imaginal density, metaphorical richness, symptom-image intensity, integrative pressure, literalizing force, diagnostic dominance, clinical containment, archetypal depth, aesthetic richness, and flattening risk can be represented transparently in conceptual modeling.

## Repository purpose

This article argues that archetypal psychology represents a radical post-Jungian revision that shifts the center of gravity from integration and individuation toward image, plurality, imagination, soul-making, and polycentric psychic life.

The code examples extend that argument through:

- synthetic archetypal-depth simulation;
- polycentric symbol-network modeling;
- integrative-pressure and flattening-risk demonstration;
- reproducible tables and figures;
- multi-language computational scaffolding;
- documented responsible-use limits.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Run the R simulation in `r/simulate_archetypal_depth.R`.
3. Run the Python network workflow in `python/polycentric_symbol_network.py`.
4. Use `sql/schema.sql` to inspect the synthetic archetypal-depth structure.
5. Treat all outputs as illustrative and synthetic, not empirical findings.
