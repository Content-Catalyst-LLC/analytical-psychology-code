# Data Dictionary

The dataset in `data/raw/synthetic_archetypal_depth.csv` is synthetic and illustrative. It does not represent real patients, dream reports, clinical records, literary corpora, or empirical findings.

| Field | Description |
|---|---|
| `case_id` | Synthetic row identifier |
| `presentation_type` | Illustrative imaginal or clinical-cultural presentation type |
| `time` | Synthetic time period |
| `psychic_plurality` | Stylized degree to which multiple imaginal centers remain active |
| `imaginal_density` | Stylized density of image, mood, mythic atmosphere, and fantasy form |
| `metaphorical_richness` | Stylized richness of metaphor, rhetoric, and symbolic language |
| `symptom_image_intensity` | Stylized intensity with which symptom appears as an image-bearing event |
| `integrative_pressure` | Stylized pressure to synthesize, unify, or organize psyche around a central norm |
| `literalizing_force` | Stylized tendency to reduce image into literal explanation, mechanism, or single meaning |
| `diagnostic_dominance` | Stylized dominance of diagnostic classification over imaginal attention |
| `clinical_containment` | Stylized degree of safety, grounding, relational holding, and responsible clinical boundary |
