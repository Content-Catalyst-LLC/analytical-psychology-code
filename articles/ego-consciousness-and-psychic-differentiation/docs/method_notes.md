# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological, clinical, therapeutic, diagnostic, personality-assessment, predictive, or mental-health measures and should not be interpreted as measurements of real people.

## Modeling logic

The article’s core claim is that the ego is the center of consciousness, not the whole psyche. A simplified ego-coherence model is:

```text
ego coherence =
  differentiation
  + reflective flexibility
  - unconscious pressure
  - one-sidedness
```

A simplified strain model is:

```text
psychic strain =
  one-sidedness
  + unconscious pressure
  + shadow activation
  + ego rigidity
  - reflective flexibility
```

A simplified individuation-readiness model is:

```text
individuation readiness =
  ego coherence
  + reflective flexibility
  + function balance
  - ego inflation
  - psychic strain
```

A simplified network model is:

```text
The ego coordinates conscious contents while remaining influenced by
functions, persona, shadow, complexes, body affect, symbolic imagery, and
reflective flexibility.
```

## Interpretive safeguards

- The ego is not the whole psyche.
- Ego strength is not ego inflation.
- Differentiation is not the same as wholeness.
- Function dominance can become one-sidedness.
- Persona identification can narrow consciousness.
- Symbolic imagery should not be treated as command or assessment.
- Crisis, trauma, suicidality, psychosis, mania, severe dissociation, or unstable reality testing require appropriate professional care, not symbolic speculation.
