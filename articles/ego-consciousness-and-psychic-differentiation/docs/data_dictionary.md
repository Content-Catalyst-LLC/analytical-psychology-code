# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real people, therapy records, clinical material, dream records, personality assessments, mental-health assessments, employment records, or empirical findings.

## `synthetic_ego_differentiation_panel.csv`

| Field | Description |
|---|---|
| `case_id` | Synthetic case-period identifier |
| `person_id` | Synthetic person identifier |
| `time` | Ordered synthetic developmental time step |
| `dominant_pattern` | Synthetic pattern such as balanced differentiation, function dominance, persona identification, or shadow pressure |
| `differentiation` | Stylized differentiation capacity |
| `function_balance` | Stylized balance across functions or domains |
| `reflective_flexibility` | Stylized capacity to reflect under pressure |
| `unconscious_pressure` | Stylized pressure from unconscious contents |
| `persona_identification` | Stylized identification with public role or social mask |
| `shadow_activation` | Stylized activation of disowned material |
| `one_sidedness` | Stylized imbalance between differentiation and balance |
| `ego_coherence` | Synthetic ego coherence score |
| `ego_rigidity` | Synthetic rigidity score |
| `ego_inflation` | Synthetic inflation-risk score |
| `psychic_strain` | Synthetic strain score |
| `individuation_readiness` | Synthetic readiness-for-depth-work indicator |

## `ego_network_nodes.csv`

| Field | Description |
|---|---|
| `node` | Psychic-domain node in a conceptual network |
| `cluster` | Broad cluster such as conscious center, function, adaptation, unconscious, embodied, reflective, or symbolic |
| `activation` | Synthetic activation value |
| `notes` | Interpretive note |

## `ego_network_edges.csv`

| Field | Description |
|---|---|
| `source` | Source node |
| `target` | Target node |
| `weight` | Synthetic relationship weight |
| `notes` | Interpretive note |

## Responsible-use note

These variables are conceptual demonstrations. They are not validated psychological, clinical, therapeutic, diagnostic, predictive, personality, dream-interpretive, or assessment measures.
