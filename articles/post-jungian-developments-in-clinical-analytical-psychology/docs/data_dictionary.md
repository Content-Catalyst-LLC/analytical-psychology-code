# Data Dictionary

The dataset in `data/raw/synthetic_post_jungian_clinical_models.csv` is synthetic and illustrative. It does not represent real patients, analysts, clinics, case files, treatment outcomes, or empirical findings.

| Field | Description |
|---|---|
| `model_id` | Synthetic row identifier |
| `school_tendency` | Illustrative post-Jungian tendency or clinical orientation |
| `time` | Synthetic time period |
| `symbolic_depth` | Stylized strength of dream, symbol, complex, archetypal, and individuation-oriented depth |
| `relational_sophistication` | Stylized attention to transference, countertransference, enactment, rupture, repair, and analytic field |
| `developmental_precision` | Stylized attention to infancy, early environment, object relations, attachment, and self-formation |
| `trauma_sensitivity` | Stylized care around dissociation, fragmentation, stabilization, safety, pacing, and overwhelming experience |
| `embodied_regulation` | Stylized attention to body, affect regulation, autonomic state, somatic memory, and nervous-system pacing |
| `cultural_responsiveness` | Stylized attention to gender, race, culture, coloniality, power, and the social field |
| `doctrinal_rigidity` | Stylized tendency to overapply Jungian theory, archetypal interpretation, or school loyalty |
| `fragmentation_load` | Stylized level of fragmentation or dissociation that limits symbolic readiness |
| `affect_tolerance` | Stylized capacity to experience affect without collapse or disorganization |
| `relational_holding` | Stylized quality of containment, trust, attunement, and therapeutic holding |
| `grounding_capacity` | Stylized capacity to remain present, oriented, regulated, and reality-connected |
