# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s comparative argument. The variables are not validated psychological scales and should not be interpreted as measurements of real people, patients, clinicians, dreams, or therapy outcomes.

## Modeling logic

The article’s core claim is that Freud and Jung founded different depth-psychological architectures.

A simplified Freudian orientation is:

```text
Freudian score =
  repression
  + sexuality conflict
  + infantile history
  + defense intensity
  + transference pressure
  - mythic amplification
```

A simplified Jungian orientation is:

```text
Jungian score =
  compensation
  + archetypal density
  + prospective development
  + mythic amplification
  + symbolic coherence
  + individuation pressure
  - repression
```

A simplified integrative depth score is:

```text
integrative depth =
  repression
  + defense intensity
  + transference pressure
  + compensation
  + symbolic coherence
  + prospective development
```

## Limits

These examples are conceptual demonstrations. They should not be used for:

- diagnosis;
- therapy;
- psychological assessment;
- employee screening;
- workplace surveillance;
- individual scoring;
- clinical triage;
- claims about empirical effectiveness;
- proof or disproof of Freudian or Jungian theory.

## Recommended use

Use these files to demonstrate reproducible research structure, transparent assumptions, synthetic simulation, concept-network modeling, and conceptual-method documentation in scholarly writing.
