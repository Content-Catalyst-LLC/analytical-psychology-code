# Data Dictionary

The dataset in `data/raw/synthetic_depth_psychology_cases.csv` is synthetic and illustrative. It does not represent real patients, clinicians, case files, therapeutic outcomes, or empirical findings.

| Field | Description |
|---|---|
| `case_id` | Synthetic row identifier |
| `case_type` | Illustrative case presentation used for conceptual modeling |
| `time` | Synthetic time period |
| `repression` | Stylized Freudian variable representing return of excluded or defended material |
| `sexuality_conflict` | Stylized Freudian variable representing sexual or erotic conflict as explanatory pressure |
| `infantile_history` | Stylized Freudian variable representing developmental-history load |
| `defense_intensity` | Stylized Freudian variable representing defensive organization |
| `transference_pressure` | Stylized Freudian/psychodynamic variable representing repetition in the analytic relationship |
| `mythic_amplification` | Stylized Jungian variable representing symbolic and mythic expansion around an image |
| `compensation` | Stylized Jungian variable representing dream or unconscious correction of conscious one-sidedness |
| `archetypal_density` | Stylized Jungian variable representing intensity of archetypal or mythic patterning |
| `prospective_development` | Stylized Jungian variable representing future-oriented symbolic development |
| `symbolic_coherence` | Stylized Jungian variable representing coherence of image, dream, symbol, or personal myth |
| `individuation_pressure` | Stylized Jungian variable representing developmental demand toward integration or wholeness |
