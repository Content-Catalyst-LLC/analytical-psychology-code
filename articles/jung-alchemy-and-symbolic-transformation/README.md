# Jung, Alchemy, and Symbolic Transformation

This companion scaffold supports the article **“Jung, Alchemy, and Symbolic Transformation”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s alchemical argument into reproducible, synthetic-data workflows. The goal is not to diagnose people, recommend therapy, validate alchemy as chemistry, reduce historical alchemy to psychology, give spiritual direction, or turn symbolic transformation into a scoring instrument. The goal is to demonstrate how nigredo, albedo, rubedo, coniunctio, Mercurius, vessel strength, shadow material, one-sidedness, affective heat, vessel failure, and integration can be represented transparently in conceptual modeling.

## Repository purpose

This article argues that Jung turned to alchemy because it offered one of the richest symbolic languages of transformation: breakdown, containment, clarification, conjunction, volatility, embodiment, and the emergence of a more durable center from dark and difficult material.

The code examples extend that argument through:

- synthetic alchemical-stage data;
- transformation-score and coniunctio-index simulation;
- vessel-strength and vessel-failure risk modeling;
- dynamic opus-network modeling;
- alchemical symbol documentation;
- reproducible tables and figures;
- multi-language computational scaffolding;
- documented responsible-use limits.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, symbolic-process analysis, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, spiritual direction, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Inspect the synthetic stage data in `data/raw/synthetic_alchemical_transformation_stages.csv`.
3. Run the R workflow in `r/simulate_alchemical_transformation.R`.
4. Run the Python workflow in `python/alchemical_opus_network.py`.
5. Use `sql/schema.sql` to inspect the alchemical-stage schema.
6. Treat all outputs as illustrative and synthetic, not empirical findings.
