# Method Notes

This scaffold uses synthetic conceptual variables to illustrate the article’s argument. The variables are not validated psychological scales and should not be interpreted as measurements of real people, patients, clinicians, spiritual progress, dream sequences, alchemical texts, or clinical outcomes.

## Modeling logic

The article’s core claim is that Jungian alchemical transformation can be represented as a staged and networked process involving destabilization, clarification, embodiment, containment, opposition, volatility, and integration.

A simplified transformation-score model is:

```text
transformation score =
  nigredo pressure
  + albedo clarity
  + rubedo vitality
  + vessel strength
  - one-sidedness
  - excessive mercurial volatility
```

A simplified coniunctio model is:

```text
coniunctio index =
  relation between opposing poles
  - destructive distance between opposing poles
  + vessel strength
```

A simplified vessel-failure model is:

```text
vessel failure risk =
  max(0, affective heat + shadow intensity - vessel strength)
```

## Limits

These examples are conceptual demonstrations. They should not be used for:

- diagnosis;
- therapy;
- psychological assessment;
- spiritual direction;
- treatment assignment;
- employee screening;
- workplace surveillance;
- individual scoring;
- clinical triage;
- claims about empirical effectiveness;
- proof or disproof of alchemy, Jungian psychology, or individuation theory.

## Recommended use

Use these files to demonstrate reproducible research structure, transparent assumptions, synthetic simulation, dynamic symbol-network modeling, and conceptual-method documentation in scholarly writing.
