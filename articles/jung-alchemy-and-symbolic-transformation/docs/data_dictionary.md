# Data Dictionary

The files in `data/raw/` are synthetic and illustrative. They do not represent real patients, dreams, clinical outcomes, alchemical experiments, spiritual development, or empirical findings.

## `synthetic_alchemical_transformation_stages.csv`

| Field | Description |
|---|---|
| `case_id` | Synthetic row identifier |
| `symbolic_stage` | Illustrative alchemical-symbolic stage or state |
| `time` | Synthetic time period |
| `nigredo_pressure` | Stylized blackening/destabilization pressure |
| `albedo_clarity` | Stylized clarification, washing, and differentiation |
| `rubedo_vitality` | Stylized embodied vitality and integration |
| `vessel_strength` | Stylized containment capacity or symbolic vessel strength |
| `onesidedness` | Stylized unresolved one-sidedness or polarized conscious attitude |
| `mercurial_volatility` | Stylized instability, ambiguity, mediation, and trickster volatility |
| `shadow_intensity` | Stylized intensity of rejected or disowned material |
| `affective_heat` | Stylized psychic heat or affective intensity |
| `pole_x` | Synthetic first pole in an opposition relation |
| `pole_y` | Synthetic second pole in an opposition relation |
