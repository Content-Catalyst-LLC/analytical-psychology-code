# Data Dictionary

The dataset in `data/raw/synthetic_jungian_critique.csv` is synthetic and illustrative. It does not represent real people, patients, clinicians, cultures, religions, or empirical findings.

| Field | Description |
|---|---|
| `concept_id` | Synthetic row identifier |
| `concept_family` | Jungian concept family represented in the critique model |
| `time` | Synthetic time period |
| `interpretive_breadth` | Stylized capacity of a concept to connect many symbolic, clinical, cultural, or philosophical materials |
| `empirical_support` | Stylized degree of empirical or outcome-oriented warrant |
| `cultural_specificity` | Stylized attention to historical, cultural, linguistic, religious, and political context |
| `gender_critical_revision` | Stylized degree to which gendered assumptions have been revised or made historically accountable |
| `methodological_explicitness` | Stylized clarity about claim type, warrant, limits, and possible disconfirmation |
| `clinical_utility` | Stylized usefulness in therapeutic, reflective, or clinical contexts |
| `symbolic_usefulness` | Stylized usefulness for interpreting dream, myth, ritual, image, and symbolic life |
| `universalization` | Stylized tendency to overgeneralize across cultures, histories, or cases |
| `problematic_inherited_assumptions` | Stylized burden of outdated or problematic assumptions in the inherited concept |
