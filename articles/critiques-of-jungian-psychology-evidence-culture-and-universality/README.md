# Critiques of Jungian Psychology: Evidence, Culture, and Universality

This companion scaffold supports the article **“Critiques of Jungian Psychology: Evidence, Culture, and Universality”** in the Analytical Psychology, Symbolism & the Depth Mind knowledge series.

The repository materials translate the article’s critical argument into reproducible, synthetic-data workflows. The goal is not to diagnose individuals, validate or invalidate Jungian psychology as a whole, rank cultures, evaluate religions, or create psychological scoring instruments. The goal is to demonstrate how interpretive breadth, empirical support, cultural specificity, gender-critical revision, methodological explicitness, clinical utility, symbolic usefulness, universalization, and problematic inherited assumptions can be represented transparently in conceptual critique models.

## Repository purpose

This article argues that critique is not the enemy of analytical psychology. It is one of the conditions under which depth psychology can remain credible. The code examples extend that argument through:

- synthetic critique-and-credibility simulation;
- competing-claims network modeling;
- overgeneralization-risk demonstration;
- retained-value-after-critique modeling;
- reproducible tables and figures;
- multi-language computational scaffolding;
- documented responsible-use limits.

## Responsible-use statement

These materials are for synthetic-data research, methods demonstration, conceptual modeling, institutional learning, and reproducible workflows. They are not intended for diagnosis, therapy, psychological assessment, clinical decision-making, cultural ranking, religious evaluation, employment screening, workplace surveillance, individual performance management, or individual evaluation.

## Suggested workflow

1. Review `article-metadata.yml` for article context.
2. Run the R simulation in `r/simulate_jungian_critique.R`.
3. Run the Python critique network in `python/critique_network.py`.
4. Use `sql/schema.sql` to inspect the synthetic critique-model structure.
5. Treat all outputs as illustrative and synthetic, not empirical findings.
